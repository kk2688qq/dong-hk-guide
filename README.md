# 香港留学指南

> 为考虑去香港读书的家庭，提供**可查证**的决策参考。每一条都写清：要花什么 / 换回什么 / 依据是哪份官方文件。

**最后更新：2026-10-05 ｜ 已收录：X 条 ｜ 待核实标记：X 处**

---

## 这本指南是什么

- 覆盖：赴港读书的主要路径（读研 / 读本科 / 副学位 / 中小学插班 / 陪读与身份联动）；
- 每条统一回答三个问题：**花掉什么、换回什么、证据有多硬**；
- 证据分三级：**A**＝官方文件原文（入境处 / 教育局 / 大学官网）｜**B**＝主流媒体或权威二手｜**C**＝作者经验，明确标注；
- **只引官方文件和期刊论文**。查不到原文的数字，宁可不写，标「待核实」；
- 免费开放，欢迎挑错：[提一个 issue](../../issues/new) —— 有错 48 小时内核对回复。

## 怎么用

1. 先读与你情况对应的条目，注意每条的证据等级；
2. 拿不准的，点进条目末尾的**官方原文链接**自己核对一遍；
3. 遇到任何中介说法与本指南冲突时，以官方文件为准，并欢迎开 issue 告诉我们。
