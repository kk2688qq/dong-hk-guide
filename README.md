## 这份指南是什么

- **范围**：中国香港——升学路径（本科 / 硕士）与身份路径（高才通 / IANG / 受养人 / 居留权）。**不做**其他地区。
- **每条**统一回答：要花什么（钱、时间、资格）／换回什么（学位、身份、时间线）／漏掉会怎样（常见误传）／官方依据（可点开的原文链接）。
- **证据分三级**：
  - **A**＝官方文件原文（入境处指南 PDF、大学官网费用页、政府新闻公报）
  - **B**＝官方二手（官方统计报告、官方问答页）
  - **C**＝作者经验，**必须显式标注**
- **只引官方文件和院校官网**。查不到原文的数字，宁可不写，标「官方尚未公布」——**公开官方尚未公布的项数，就是公开自己的诚实度**。

## 怎么读

- **不用全做**：这是一份按风险高低排好的**备选单**，不是任务清单。挑走一条就算数，剩下的放着，需要时再回来查。
- **想快速拿主意**：看每条开头的**「说人话」方框**——它把这一条的关键结论压成几句话，只看它就够拿主意。要核对数字、要看官方原文，再展开下面的折叠（「展开明细」与「官方依据与审核信息」）。

- **想离线看、想发给别人**：下载[单文件 HTML](../../releases/download/book-latest/HKStudyGuide.html)。整本书连同搜索和筛选都在这一个文件里，**双击就开，不用联网，微信里能直接传**。

- **三样都是正文每次更新后自动重新生成的**，下载链接固定不变；转发出去的那份不会跟着更新，以[在线版](https://kk2688qq.github.io/dong-hk-guide/)为准。

## 三条铁律（本项目自我约束）

1. **条目标题不带品牌词**——标题按用户会搜的词写（「高才通 A 类收入门槛」，不是「董老师谈高才通」）。品牌词是栏目层的东西，不进条目层。
2. **通用词与品牌词并行**——通用词（香港升学 / 香港读研 / 高才通）是被发现的**入口**，管自然流量；「董老师香港留学指南」是被搜索的**目标**，管精准转化。谁也不吃掉谁。
3. **宁少一条，不可错一条**——全部价值建立在「读者能自己验证」之上。为了一次性好看而放松信源标准、或为了转化加一句承诺，就是**一次性烧掉全部积累**。
