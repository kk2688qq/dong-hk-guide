## 这份指南是什么

- **范围**：中国香港——升学路径（本科 / 硕士）与身份路径（高才通 / IANG / 受养人 / 居留权）。**不做**其他地区。
- **每条**统一回答：要花什么（钱、时间、资格）／换回什么（学位、身份、时间线）／漏掉会怎样（常见误传）／官方依据（可点开的原文链接）。
- **证据分三级**：
  - **A**＝官方文件原文（入境处指南 PDF、大学官网费用页、政府新闻公报）
  - **B**＝官方二手（官方统计报告、官方问答页）
  - **C**＝作者经验，**必须显式标注**
- **只引官方文件和院校官网**。查不到原文的数字，宁可不写，标「待核实」——**公开剩余待核实数，就是公开自己的诚实度**。

## 怎么用

1. 先读与你情况对应的条目，注意每条的**证据等级**；
2. 拿不准的，点进条目末尾的**官方原文链接**自己核对一遍；
3. 遇到任何中介说法与本指南冲突时，**以官方文件为准**，并欢迎开 issue 告诉我们。

## 三条铁律（本项目自我约束）

1. **条目标题不带品牌词**——标题按用户会搜的词写（「高才通 A 类收入门槛」，不是「董老师谈高才通」）。品牌词是栏目层的东西，不进条目层。
2. **通用词与品牌词并行**——通用词（香港升学 / 香港读研 / 高才通）是被发现的**入口**，管自然流量；「董老师香港升学手册」是被搜索的**目标**，管精准转化。谁也不吃掉谁。
3. **宁少一条，不可错一条**——全部价值建立在「读者能自己验证」之上。为了一次性好看而放松信源标准、或为了转化加一句承诺，就是**一次性烧掉全部积累**。
