# 术语表：先把词弄准，再看数字

香港这套制度里，**最容易踩的坑不是数字错，是词用错**。同一个词，家长的理解和官方文件里的定义常常不是一回事。**下面这些词，看懂了再读条目。**

## 一、最容易搞混的两组

| 术语 | 官方是什么意思 | 为什么容易错 |
| --- | --- | --- |
| **联招年度**（如「2027 年度」） | 指 **2027 年 9 月入读**那一次招生 | 与「学年」常被当成两回事，其实是**同一年** |
| **学年**（如「2027/28 学年」） | 指 **2027 年 9 月至 2028 年 8 月** 这个教学年度 | **计算窗口往往在入读前一年**——家长会误当成「孩子入读那一年才开始算」 |
| **本地生 / 非本地生** | 高校收生分类中的两档，与学费、学额相关；**非本地生学费约为本地生的 4.6–5.3 倍** | 与「有没有香港身份」不是同一件事；**受养人子女的居留规定改的是联招申请资格，不是笼统的「本地生认定」**（第 HK-031 条） |
| **受养人签证** | 由在港的保证人担保、随其来港居留的签证类别 | 家长常以为「受养人＝本地生」或「受养人不能读书」，都不准（第 HK-024 条、第 HK-031 条） |

## 二、升学相关的词

| 术语 | 一句话 |
| --- | --- |
| **JUPAS（大学联招办法）** | 香港本地生的**统一报大学**系统，由大学联招处运营。**内地应届高考生走不了**（第 HK-001 条、第 HK-031 条） |
| **非联招（Non-JUPAS）** | 不走联招的入学途径，直接向院校申请。持国际资历的学生、持非本地学历的学生走这里（第 HK-050 条） |
| **DSE（香港中学文凭考试）** | 香港的「高考」，对应考评局（第 HK-038 条、第 HK-039 条） |
| **Band** | 香港中学的分档说法，由小学升中派位机制衍生（第 HK-033 条） |
| **副学士** | 两年制的副学位课程，可衔接本科高年级。**不是保底**（第 HK-018 条） |
| **提前批 / 统招** | 内地高考志愿的录取批次。**走统招提前批的港校只有香港中文大学（本部）**；**香港中文大学（深圳）、香港科技大学（广州）是另两所机构，也各有提前批**（第 HK-001 条、第 HK-054 条） |
| **条件录取 / 无条件录取** | 前者带「先满足某个条件」的条款（如最终成绩、补交材料），后者是直接录取。**付款前必须分清**（第 HK-014 条） |
| **留位费** | 接受录取时要交的「占位」费用，通常约定不退或部分可退。**规则以你那份 offer 的书面条款为准**（第 HK-013 条） |

## 三、身份相关的词

| 术语 | 一句话 |
| --- | --- |
| **高才通（高端人才通行证计划）** | 分 A／B／C 类，A 类看**过去一年收入**，B／C 类看**学历与工作经验**（第 HK-019 条、第 HK-020 条） |
| **优才（优秀人才入境计划）** | 分**综合计分制**与**成就计分制**两条路（第 HK-021 条） |
| **专才（输入内地人才计划）** | 靠**先拿到香港雇主聘用**过去（第 HK-022 条） |
| **学生签证** | 来港读书的签证；**抵港后 30 天内**要办身份证，不是 7 天（第 HK-008 条、第 HK-017 条） |
| **IANG（非本地毕业生留港／回港就业安排）** | 毕业后留港工作的**逗留安排**——**不是身份**。首次 24 个月，续期须已获聘用（第 HK-023 条、第 HK-029 条） |
| **大湾区校园毕业生** | 就读「内地与香港合作办学机构」全日制课程并获学士或更高资历者，**同样可依 IANG 申请来港工作**（第 HK-054 条） |
| **通常居住** | 永居条件里「连续通常居住七年」的说法。**在不在港、怎么算，属于个案认定**（第 HK-026 条） |
| **居留权 / 永久性居民身份** | 「可以申请」与「一定获批」是两回事；**本书只复述官方条款，不作个案结论**（第 HK-026 条） |

## 四、读数字时的三条纪律

1. **每个数字都要带年份或学年**——学费年年调整，政策按年度表述。本书所有金额与门槛都写明学年；没有年份的数字，不要引用。
2. **「官方没公布」也是结论**——例如官方的录取线、认可院校名单，查不到就写「官方不公布／未核到」，**不拿网传数字填空**（第 HK-047 条即为此例）。
3. **一个事实只有一个来源**——本书每条末尾列官方链接，且每条都有公开的**核实记录**。两处口径不一致时，以**官方原文**为准，并去看核实记录里怎么处理的。
