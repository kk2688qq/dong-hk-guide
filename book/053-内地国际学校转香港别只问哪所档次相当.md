# HK-053 内地国际学校转香港：别只问「哪所档次相当」

<!-- 风险=高 阶段=怎么选 焦虑=防骗 -->

**说人话**

香港的「国际学校」**不是一个模糊概念**——教育局名册上写得清清楚楚：**53 所国际学校、8 所私立独立学校，另有 21 所直资学校办非本地课程**。它们全部自负盈亏，**没有统一招生、也没有统一派位**：各校**自己定要求、自己定程序**，要**直接找各校招生办**。

所以「**哪所档次相当**」这个问题，**问错了方向**——官方从来不给「学校档次」这种口径，谁给都是私下判断。真正能核、也该问的是三件事：**① 你孩子的年龄与学段，对应哪一所的哪个年级；② 那一所的申请窗口什么时候开；③ 除了面试，它还可能看什么、还要收什么钱。**

**要花什么**

查官方名册不花钱，花的是**提前量**。

- **钱**：官方名册与检索页免费。**但注意**：部分学校会走**提名权（nomination rights）、债券（debentures）、资本建设费（capital levies）**——这是**官方自己写出来**的，性质是先付费换取「被考虑」，**不是保录**。**申请前把条款读完**。
- **时间**：官方明说申请「**通常在学年开始前约一年**」开放，有的甚至更早；**有的全年滚动收、有的固定截止**。官方原话是「至少提前一年以上规划」。
- **精力**：把「孩子年龄／学段 → 候选学校 → 该校收生年级 → 申请窗口」对齐。
- **要核对的硬项**：① 孩子**当前年龄 + 在读年级**；② 目标**课程体系**（IB／英式／美式／澳式／加式／法式／德式／日式／韩式／新加坡等）；③ 目标学校在**官方名册**上的**年龄区间与学段**；④ 该校**申请开放与截止**；⑤ 是否涉及债券／提名权／资本建设费，条款是什么。

**换回什么**

换回一份**可核的候选清单**——按年龄、学段、课程体系、地区、学费在**官方检索页**上筛出来的**具体校名**，以及每所的**申请窗口**与**可能的非学术因素**。这比「哪所档次相当」实在，而且**每一条都能自己复核**。

**官方三类名册（数量与课程，均为教育局原文）**

| 类别 | 官方数量 | 说明 |
| --- | --- | --- |
| **国际学校** | **53 所** | 一般提供**非本地课程** |
| **私立独立学校** | **8 所** | 同上，自负盈亏 |
| **直资学校（办非本地课程）** | **21 所** | 本地直资但开设非本地课程 |

**非本地课程体系**（官方列举）：**IB 文凭课程**，以及**澳大利亚、加拿大、法国、德国、日本、韩国、新加坡、英国、美国**等国的课程。

**官方名册怎么用**（这才是「选校」该有的起点）：

教育局「School Search」支持按 **年龄（3–18+）／学段（小学／中学／中小学）／学费／课程体系／授课语言／地区** 检索；**每一条都给出学校名、地址、收生年龄区间、学段、每年学费、网址、电话**。举例（官方公开事实，**不是推荐**）：某校标注 **Age 16–18 · Secondary**、某校 **Age 6–18 · Primary cum Secondary**、某校 **Age 5–18 · Primary cum Secondary**。

→ **「收生年级」的官方可核实抓手，就是「年龄区间 ＋ 学段」**——不是坊间的「档次」说法。

**官方自己提示的两件「非学术」事**（原文，务请留意）

1. **录取优先级可能看非学术因素**：官方原文写，除评估与面试表现外，这些学校可能**「对申请者的国籍、商会推荐、兄姊在读、教职员子女等因素给予有利考虑」**。
2. **可能设提名权／债券／资本建设费**：官方原文点名 **nomination rights schemes、debentures schemes、capital levies**，并提醒**申请与认购前务必完全理解条款**。

**这两条是官方口径，不是坊间猜测**——所以「交钱就能进」不是我们的推断，是**官方自己在风险提示里点出来的**。

**红线提醒**

- **别把「档次相当」当选校方法**——**官方没有任何「学校档次／排名」口径**。内地国际学校与香港学校之间**没有官方换算表**；拿「档次」当锚，等于用一个**不存在的标准**做决定。
- **别先付债券再看条款**——官方明确把提名权／债券／资本建设费列为**需先读懂条款**的事项；先付费、后了解，是最常见的失手方式。
- **别忽略「年级对应」不是一一对应**——官方明说：读非本地课程时，**入学年龄与本地课程的「小一／中一」可能略有差异**，因为**入学年龄对应的是课程体系本身**。用内地年级直接套香港年级，会错。
- **别把它当成统招**——**没有统一招生、没有统一派位**，各校自订；「等派位」「等统一报名」都会错过窗口。

**常见误传**

1. **「香港国际学校有个官方排名／档次表」**——**不存在**。官方只提供**名册**（校名、地址、年龄、学段、学费、课程、语言、地区），**从不排名、不评档次**。
2. **「内地某校的档次，可以对到香港某校」**——**无官方依据**。两地问没有官方换算关系；能核的是**年龄／学段／课程体系**是否对得上。
3. **「交债券／提名权就能保证录」**——官方原文只说这会带来「**favourable consideration**（有利考虑）」，**不是保证录取**；且官方提醒**先读懂条款**。
4. **「等统一招生通知」**——香港国际学校**没有统一招生**；各校自订，**申请通常在开学前约一年开放**，错过就等下一年。
5. **「年级照内地数字直接对应」**——官方明说非本地课程的**入学年龄与本地课程「小一／中一」可能略有差异**；**必须按该校课程体系的年龄／学段核**。

**适用人群 + 入学年度**

- **谁该看**：孩子在内地读**国际学校／国际课程**、考虑**转到香港读中学**的家庭；以及想用官方名册「自己筛候选清单」的家庭。
- **入学年度**：以**教育局名册现行版**（2026-10-07 核）与**各校官网当年度招生页**为准；各校日期**逐年不同**。

**解决什么焦虑 + 风险等级 + 决策阶段**

- **风险等级**：高——**用错方法选校**（追「档次」）或**先付债券后看条款**，代价直接是钱和一年时间。
- **解决什么焦虑**：防骗（有没有官方名册、债券意味着什么、不通过中介能不能自己做）。
- **决策阶段**：怎么选（在挑学校、定申请顺序时用）。

**关键节点与时效**

- **官方名册**：教育局「国际学校」站点的 School Search 与「Useful school lists」，**持续更新**，用前重开。
- **申请窗口**：官方口径为「**开学前约一年**」，**各校差异大**（滚动／固定截止并存）——**逐校去官网核**，不要用一份汇总表代替。
- **本地课程中学名册**另走**《中学概览（CHSC）》**，与国际学校名册**分列**——两条线不要混。
