# HK-026 「通常居住连续七年」永居怎么算

<!-- 风险=高 阶段=怎么落地 焦虑=确定性 -->

**说人话**

香港的永久居民身份不看签证类型，只看一件事：合法居留、以定居为目的，在港通常居住连续满七年。读书、工作、办身份期间都算，偶尔离港不算断。办下来要确立身份，也就是居留权证明书、特区护照或永久性居民身份证。中国公民拿到后长期不在港也不会失去。

**要花什么**

搞清楚这件事：不花钱、不跑腿，把官方这几页翻一遍就行。要核对的是六件事——

- **钱**：不花。所有官方信息都免费公开。
- **时间**：几小时。官方定义页 + 资格一览表 + 居留权证明书填表须知，三页看完。
- **精力**：不用改习惯、不担风险，查完就能判断自己差在哪一段。
- **要核对的硬项**：① 我这七年里，每一段逗留是不是合法（有没有违反过逗留条件）；② 七年是否「连续」（离港的原因、期间、次数）；③ 在港有没有惯常住所、是否受雇于以香港为基地的公司；④ 主要家庭成员（配偶及未成年子女）在不在香港；⑤ 有没有踩到官方明文排除的情形（在囚、外籍家庭佣工、驻港部队成员、政府输入雇员计划下的外来合约工人等）；⑥ 到时用哪种文件确立身份。

**换回什么**

换回的是「我的这七年到底算不算」这个判断，以及「居留权」本身是什么。

**居留权包含四项权利**（官方原文）：① 香港特区的入境权；② 在香港特区不会受任何逗留条件（包括居留期限）的限制；③ 不会被递解离境；④ 不会被遣送离境。

**「通常居住」的官方定义**（这是全条的核心）：任何人如果是**合法、自愿和以定居为目的**而在香港居住（例如**读书、工作或居留**等），**不论时间长短**，会被视为通常居住在香港；如果他/她**只是暂时不在香港，仍会被视为是通常居住在香港**。

**判定「是否已不再通常居住」看四个因素**：① 不在香港的原因、期间及次数；② 是否在香港有惯常住所；③ 是否受雇于以香港为基地的公司；④ 其主要家庭成员（配偶及未成年子女）的所在地。

**身份怎么「确立」**（中国公民）：永久性居民身份只可藉持有以下任一文件确立——① 发予本人、已附贴于有效旅行证件上的**有效居留权证明书**；或 ② 发予本人的**有效香港特区护照**；或 ③ 发予本人的**有效永久性居民身份证**。

**中国公民与非中国公民的差别**：中国公民只要仍是**中国公民**，将继续享有居留权，**即使长时间不在香港，也不会丧失永久性居民的身份**；非中国公民则按《入境条例》附表 1 (d) 项——须通常居住连续七年（且该七年**须是紧接申请日期之前**的连续七年）、须以香港为永久居住地作出声明并提交资料，**未获入境事务处处长批准前，不具有永久性居民身份**。

**红线提醒**

- **别把「违反逗留条件」的时间算进去**——官方明文：在违反任何逗留条件的情况下留在香港，**不会**被视为通常居住在香港。
- **别把被监禁或羁留的时间算进去**——官方明文：依据法院判处或命令被监禁或羁留的任何期间，**不算**通常居住。
- **别把这几类期间算进去**：外籍家庭佣工、驻港部队成员、领馆人员、政府输入雇员计划下的外来合约工人、订明的中央政府旅行证件持有人——官方逐项排除。
- **别造假居住证明**——虚假陈述、使用虚假文书属刑事罪行，身份和记录一起没。
- **别以为「满七年就自动是永久居民」**——中国公民还要**确立**身份（三件文件之一）；非中国公民更须**申请并经处长批准**。

**常见误传**

1. **「七年内必须天天在香港」**——错。官方定义写明：只是暂时不在香港，**仍会被视为通常居住在香港**。
2. **「每年不能离港超过 90 天」**——那是**大学联合招生办法（JUPAS）申请资格**的居港规定（见第 HK-031 条），不是永居七年的要求。两者常被混为一谈，适用对象完全不同。
3. **「读书那几年不算居港」**——错。官方定义举例就是「例如**读书**、工作或居留等」，合法居留的读书期间计入通常居住。
4. **「拿到签证满七年，自动就是永久居民」**——错。中国公民须**确立身份**（居留权证明书／香港特区护照／永久性居民身份证）；非中国公民还须**申请并获处长批准**，批准前不具有该身份。
5. **「离开香港久了，身份就没了」**——对**中国公民**不成立：官方原文「即使有关人士长时间不在香港，亦不会丧失其永久性居民的身份」。
6. **「坐牢那段也算居留」**——错，官方明确排除被监禁或羁押的期间。

**适用人群 + 入学年度**

- **谁该看**：已通过高才通／优才／专才／IANG／学生签证在港、正在算「还差几年能拿永居」的人；以及替孩子规划「读几年、留几年、什么时候够七年」的家长。
- **入学年度**：不适用（身份线，与院校入学年度无关）。

**解决什么焦虑 + 风险等级 + 决策阶段**

- **风险等级**：高——七年算错就是身份落空、白等一轮；若为「凑七年」在居住证明上动手脚，还可能涉刑事。
- **解决什么焦虑**：确定性（我这七年到底算不算、断在哪一段、哪些时间不算）。
- **决策阶段**：怎么落地（已在港或准备来港，规划七年的居住轨迹）。

**关键节点与时效**

- 七年按**连续**计算，判定看官方四因素 + 八类明文排除情形（见上）。
- **居留权证明书**：须在**香港以外地区**向入境事务处处长提出；**内地申请人**通过**当地公安机关出入境管理部门**递交；**申请免费**。
- 处理时间：在通常情况下，**95% 的居留权证明书申请可在入境处接获所需文件后三个月内完成处理**——但若申请人与声称父母关系存疑或资料存疑，**不适用**该标准。
- 中国公民**长期不在港亦不丧失**居留权；非中国公民另有丧失机制（见《丧失香港永久性居民身份》页，本条未逐句核对）。
