# HK-020 高才通 B 类和 C 类：学历、工作经验与配额门槛

<!-- 成本标签: 钱=0 时间=少 精力=否 收益=大 口径=结果 -->

**说人话**

高才通不只有「年收入 250 万」那条路。世界百强大学的学士学位，也能走——毕业五年内攒够三年工作经验就是 B 类；攒不够三年也能申请，算 C 类，但 C 类有年度配额、先到先得，还可能排不上。B 类和 C 类首次都给 24 个月（比 A 类少一年）。申请时不要求先找到工作，但**续签时必须证明你在香港有工作或生意**。另外，在香港读本科的非本地学生**不能**走 C 类。

**要花什么**

搞清楚这条门槛：不花钱、不耗时，几分钟看完。真正的门槛有三条——

- **学历**：必须是**合资格大学**颁授的**学士学位**。
  - 合资格大学＝入境处「综合名单」收录的院校：过去五年在泰晤士高等教育、QS、美国新闻与世界报道、上海交大四个世界大学排名里进过百强的院校；另有 QS「酒店及休闲管理」前五的酒店专门院校、上海交大「中国大学排名」前二十的内地大学、QS「艺术与设计」前五的专科学院（官方注 2）。
  - **不接受**：从合资格大学设立的**持续及专业教育学院、分校、延伸学院或附属学院**取得的学历（官方注 2 明文排除）。
- **工作经验**（关键分水岭）：
  - **B 类**：紧接申请前**五年内累积至少三年**工作经验。
  - **C 类**：工作经验**少于三年**（含应届），受**年度配额限制、先到先得**。
- **先在港找工作**：不需要——申请时无须已获香港雇主聘用。
- **费用**：须缴**不可退还**的申请费与签发费，主申请人与每名受养人分别计，金额随官方调整（点「官方依据」第 3 项查现行数字）。
- **等待**：文件与申请费交齐后，一般约 **4 星期**。

**换回什么**

- **首次逗留 24 个月**（B 类与 C 类相同；A 类是 36 个月），不受其他逗留条件限制——可自由打工、换工作、开公司，无须事先取得入境处处长批准。
- **续签**：逗留期满前 3 个月内网上申请；须证明已在港受聘并有稳定收入，或已在港开办／参与业务；获批一般**延长不多于 3 年**，或至雇佣合约期满（以较短者为准）。
- **B／C 类续签时可能要补件**：首次申请没提交学士学位**认证文件**的，续签时必须一并补交（第 21 段）。
- **顶尖人才（一次拿 6 年）**：在港逗留满 2 年、上一评税年度薪俸税应评税入息达 200 万港币或以上，续签可按顶尖人才类别审批，一般延长 6 年。
- **受养人**：配偶或伴侣、18 岁以下未婚子女可同来，逗留期限与主申请人挂钩；在港就业、就读不受限制——但须**各自单独申请、各自缴费**。
- **永居**：在港连续通常居住满 7 年，可依法申请居留权。

**红线提醒**

- **别用「分校／附属学院」的学历去申请**——官方注 2 明文不接受，这一条最容易在续签时才被查出。
- **别以为 C 类随时能交**——受年度配额限制、先到先得，配额分配完就等下一年度。
- **在香港读本科的非本地学生不能走 C 类**——官方第 4(c) 段明确排除；这是与 B 类的重要差别。
- **别以为「首次不用工作证明」等于「以后也不用」**——续签必须证明在港受聘或经营业务。
- **别提供虚假资料**——虚假陈述属刑事罪行；官方在核实材料时**可能进行实地探访**（第 33 段）。
- **别指望缴费能退**——不论批不批，申请费与签发费都不退。

**常见误传**

1. **「只有年收入 250 万才能走高才通」**——错。250 万只是 A 类。B 类走学历＋三年经验，C 类走学历但经验不足三年。
2. **「只要是名校毕业就行」**——错。官方只认「综合名单」的**学士学位**，且**分校、延伸学院、附属学院**的学历一律不接受（官方注 2）。
3. **「C 类门槛低，随时能申请」**——C 类受年度配额限制、先到先得；且在香港读过全日制本科的非本地学生被明确排除，不能转 C 类。
4. **「B/C 类和 A 类一样给 36 个月」**——错。官方第 7 段：**A 类 36 个月，B 类及 C 类 24 个月**。
5. **「申请时要先有香港工作」**——首次申请不需要；但续签必须证明在港受聘并有稳定收入，或已开办／参与业务（第 15、18、19 段）。
6. **「一个人批了，配偶孩子自动跟着拿」**——受养人须单独申请、单独缴费，并满足「保证人有能力提供远高于基本水平的生活和合适居所」。

**适用人群 + 阶段**

- **谁该看**：本科毕业于合资格大学、正在判断自己走 B 类还是 C 类的人；以及在香港读本科、想知道自己能不能走 C 类的非本地学生。
- **决策阶段**：身份规划起步期，还没递交申请。
- **入学年度**：不适用（身份线，与院校入学年度无关）。

**口径 + 性价比档**

- **口径**：结果（直接决定身份能否获批，不折算成金钱或时间）。
- **性价比档**：极高——分错 B／C 类、或用错学历（分校／附属学院）就是白跑一趟（收益大），而搞清楚它不花钱、只花几分钟（三项成本全为零）。

**关键节点与时效**

- 官方指南版本：**ID(C)1026（04/2026）**（现行版；旧版 03/2026 段落号已重排，引用务必按当前版核对）。
- **C 类受年度配额限制，先到先得**（第 4(c)、第 6(c) 段）；A 类与 B 类不受配额限制。
- 审批约 4 星期，**不含**补件、办通行证与赴港签注的时间。
- 已缴费用一律不退款。
