# HK-040 香港插班没有统一招生日程，怎么找学校

<!-- 风险=中 阶段=怎么申请 焦虑=落地 -->

**说人话**

香港的派位制度只管中一（S1），也就是为就读参加派位小学的小六学生分配资助中一学位。中一以外的年级插班没有统一日程，空缺由各校自行处理。找学校的官方工具有《中学概览》（chsc.hk）、教育局公营中学学额空缺页、分区学校名册，以及四个区域教育服务处的「学位安排支援服务」。

**要花什么**

- **钱**：查官方工具免费。
- **时间**：逐个区、逐间校查，**没有一站式入口**，这是最花时间的地方。
- **精力**：要**主动打电话 / 发邮件**给目标校，问「有没有空缺、怎么申请」。
- **要核对的硬项**：① 目标校是**参加派位**还是**自行收生**（直资不参加派位者，申请日期由学校自订）；② 该级别有没有**空缺**；③ 学校评估的**年级**。

**换回什么**

换回的是「**不干等**」——知道没有全港统一的插班日程表，就不会干等公告；也拿到四个官方查询入口，能**自己动手找**。

**先分清：派位 vs 插班**

**① 派位只管中一**

教育局「学位分配系统」原文：

> 「学位分配系统包括小一入学统筹办法、中学学位分配办法及中四学位安排机制，均由教育局执行，为合资格的小一、中一及中四学生分配资助学位。」
> 「**中学学位分配办法**是**为符合资格并就读于参加中学学位分配办法小学的小六学生，分配资助中一学位的机制**，分为「自行分配学位」和「统一派位」两个阶段。」

**② 不参加派位者——直接向学校申请**

同上原文：

> 「至于**不参加中学学位分配办法的学生，包括新来港儿童及就读于不参加中学学位分配办法小学的学生，可直接向心仪学校申请入学**。参加中学学位分配办法的官立、资助、按额津贴及直接资助计划学校一般于**每年一月份**接受下年度的入学申请。」

**③ 非中一年级：由学校自行处理**

- 官方口径是「**公营学校在取录学生前，应按其校本机制面见申请「插班」的学生，以专业判断评定申请人适合就读的级别**」（教育局学额空缺页）。
- 《资助则例（中学）》第 11(c) 条英文原文：空缺「**may be filled at the discretion of the school Principal**」——即**由校长酌情填补**。
- **直资（不参加派位）**：教育局原文「**申请不参加中学学位分配办法的直接资助计划中学：申请日期由学校自行订定**，详情请向学校查询或浏览学校网页」。

**⚠️ 官方没有一句「插班没有统一招生日程」的原话**

- **未找到**这句原话。可用的**间接官方事实**有三条：**SSPA 只分配 S1 学位**；非 S1 空缺**由校长酌情填补**；直资（不参加派位）**申请日期由学校自行订定**。
- 因此「没有统一日程」是**由 A 级原文推出的结论**，属**推断**，**不是官方原话**。

**五个官方找校工具**

**工具一：《中学概览》（chsc.hk）**

政府新闻公报（2025-12-04）原文：

> 「家庭与学校合作事宜委员会（家校会）明日（十二月五日）发布《**中学概览 2025/2026**》网上版（中、英文版本）。全港小学亦会向本学年就读小六的学生的家长派发《中学概览》印刷本。」
> 「《中学概览》**辑录全港四百多所本地中学的基本资料，包括办学宗旨、学校设施、教师资料、班级结构、开设科目、学生支援及教学规划**。**所有资料均由学校提供并核实，反映学校截至二○二五年九月的状况。**」
> 「公众人士可浏览《中学概览》网页（**www.chsc.hk/secondary**）参阅网上版。此外，**各区民政事务处、公共图书馆及教育局区域教育服务处亦备有印刷本**。」

> **注意**：《中学概览》网上版**可由学校按需要更新**，故截图**不可当作「某日定稿」**，引用时须注**截取日期**。

**工具二：公营中学学额空缺情况**

教育局原文：

> 「基于学额空缺情况浮动，此网页的公营中学学额空缺资料**只供参考**，并会以「有学额空缺」、「仅余少量学额」和「没有学额空缺」显示。」
> 「此网页显示公营中学**每个级别**的总学额空缺情况。就个别学校高中级别选修科目和相关学额空缺资料，**请自行向有关学校查询**。」
> 「此网页的公营中学学额空缺资料**按月更新**……」

**工具三：分区学校名册**

- 教育局「分区学校名册」按 **18 区**列出（港岛：中西区 / 东区 / 离岛 / 南区 / 湾仔；九龙：九龙城 / 观塘 / 西贡 / 深水埗 / 黄大仙 / 油尖旺；新界东：北区 / 沙田 / 大埔；新界西：葵青 / 荃湾 / 屯门 / 元朗）。
- 各区分页列出**官立、资助、按额津贴、直接资助计划、私立**等学校的名称、地址、电话、校长等（页内日期 **31/08/2026**）。

**工具四：区域教育服务处「学位安排支援服务」**

教育局「新来港儿童入学安排」（修订 2026-03-19）原文：

> 「新来港儿童可透过以下途径寻求学位：
> - **家长可直接联络学校，为子女递交入学申请，学校会按其校本情况（例如是否有学位空缺）考虑有关申请。**
> - 教育局辖下的**四个区域教育服务处（包括港岛、九龙、新界东及新界西）**，会协助有需要的新来港定居学童寻找学位……可就学童的居住区域，**直接联络就近的区域教育服务处寻求学位安排支援服务**。区域教育服务处的职员会尽快安排他们的子女入学。」

教育局「学位安排支援服务」原文：

> 「家长可直接联络学校，为子女申请入读该校，或可直接联络就近的区域教育服务处同事，寻求学位安排支援服务。」
> 登记表分三款：「(a) 新来港儿童适用；(b) 香港在学儿童转校适用；(c) 跨境学童适用」

> 另据官方原文：教育局的**学位安排及支援组**会在收到邮柬 / 网上表格的**三个工作天内**联络家长。

**工具五：直资 / 私立学校官网（自行收生）**

- 直资（不参加派位者）：**申请日期由学校自行订定**，须向学校查询或浏览学校网页。
- 私立学校：教育局「局中人语」（2026-01-30）原文——「私立学校提供本地及 / 或非本地中小学正规课程，并以**自负盈亏**的模式运作，在**授课语言、课程安排、公开考试选择等方面享有弹性**」；所有私立学校均须按《教育条例》《教育规例》及相关指引合规办学。
- 官方另设「**提供正规课程的私立学校**」专题网站与「**私校名册**」（见《私立学校实务守则》相关公布）。

**⚠️ 私立学校插班没有统一规则**

- **未找到**私立学校插班收生的官方统一说明。官方只说明私立学校「享有弹性」，**没有**统一插班规则。
- 因此**「逐校查」是唯一可行的方法**，本条不编造「通用流程」。

**红线提醒**

- **别等「全港插班日程表」**——**没有**这个东西；等下去只会错过个别学校的窗口。
- **别只看《中学概览》就报名**——它反映的是**学校截至某一时点**的状况，**空缺要以学额空缺页 + 直接问学校为准**。
- **别忽略「选修科」**——官方明说「学校提供的学位未必能完全符合申请人的意愿，包括**欲就读的级别和欲修读的选修科**」。
- **别把区域教育服务处的支援当成派位**——它提供的是**协助寻找学位**，**不是**保证分配（官方原文：「区域教育服务处的职员会**尽快安排**他们的子女入学」，服务对象为**6 至 18 岁**儿童）。

**常见误传**

1. **「插班也有类似中一派位的统一时间表」**——**没有**。「中学学位分配办法」**只分配中一学位**；中一以外的插班空缺由**各校自行处理**（《资助则例（中学）》第 11(c) 条：由校长酌情填补）。
2. **「直资学校也参加统一派位」**——**分两类**。**参加**派位的直资学校按官方日期收生；**不参加**派位的直资学校，官方明文「**申请日期由学校自行订定**」。
3. **「教育局会帮你派一间学校」**——**不准确**。区域教育服务处的「学位安排支援服务」是**协助寻找学位**（官方原文「会尽快安排他们的子女入学」），服务对象是**6 至 18 岁**儿童，**不等同于保证派位**。
4. **「《中学概览》上的资料就是最新的」**——**不一定**。官方说明资料「反映学校截至二○二五年九月的状况」，且学校可**按需要在网上版更新**——**须注截取日期**。
5. **「私立学校插班有统一规则」**——**没有**。官方只说明私立学校「享有弹性」，**未见统一插班收生规则**。

**适用人群 + 入学年度**

- **谁该看**：准备为孩子插班（非中一）来港的家庭；深圳跨境家庭；正在找「从哪查起」的家长。
- **入学年度**：本条所列工具与文件为**现行版本**（《中学概览》**2025/2026**；学区名册页内日期 **2026-08-31**；「新来港儿童入学安排」修订 **2026-03-19**）。

**解决什么焦虑 + 风险等级 + 决策阶段**

- **风险等级**：中——找不到入口会**延误一整个申请季**，但属**可通过主动查询解决**的问题，不会造成身份或重大金钱损失。
- **解决什么焦虑**：落地（具体从哪查、找谁问）。
- **决策阶段**：怎么申请。

**关键节点与时效**

- **中一自行分配学位**：2027-01-04 至 01-18（**注意：这是中一派位，不是插班**）。
- **中一派位结果公布 / 注册**：2027-07-06 公布；07-08 及 07-09 注册。
- **参加派位的官立 / 资助 / 按额津贴 / 直资学校**：一般于**每年一月**接受下年度入学申请（官方原文）。
- **学额空缺页**：**按月更新**。
- **区域教育服务处**：收到表格后**三个工作天内**联络家长。

**证据等级 + 官方依据**

证据等级：**A**（教育局 / 政府新闻公报一手原文）；**「插班没有统一招生日程」的结论化表述＝C（由 A 级事实推出，须显式标注）**
