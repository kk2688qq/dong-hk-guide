# HK-005 什么样的孩子不适合去香港留学

<!-- 风险=中 阶段=要不要去 焦虑=取舍 -->

**说人话**

官方没有「什么样的孩子适合去香港」的判定标准。这一条是本指南按官方事实整理的反向提示，不是官方口径。最容易出问题的有几类：孩子自己不想去、预算只够学费、指望轻松上名校、指望读书顺便打工养自己、英语长期在及格线附近、把留下来当成必然。这些都不是能力问题，是预期和制度对不上。

**要花什么**

- **钱**：不花钱。
- **时间**：读完约 10 分钟。
- **精力**：**逐条对照自家情况**，尤其是「孩子意愿」和「预算」两条。
- **要核对的硬项**：① 孩子自己的意愿；② 家庭**能覆盖几年**的支出；③ 孩子的**英语实际水平**；④ 家庭对「读完可能回内地」的接受度。

**换回什么**

换回的是「**在花大钱之前先排掉明显的错配**」——避免用一笔几十万到上百万的投入，去验证一个本可以在家里讨论清楚的问题。

**先说明：这是经验型提示，不是官方判定**

- **官方文件里没有**「适合人群画像」「不适合人群」这类文档（教育局、考评局、入境处、各校均无）。
- 下列每一条，都**尽量挂在一条官方事实上**；**凡属推断的部分，本条会明说**。
- **本条目证据等级为 C（作者经验）**——请把它当作**提问清单**，而不是**结论**。

**十类要慎重的家庭**

**① 孩子自己不想去，只是家长想去**

- 这是**最根本的一条**。官方没有数据，但这是**三年到七年**的长期安排，孩子的意愿直接影响能不能读完。
- **提示**：把「为什么去」讲清楚，比选校更重要。

**② 预算只算得上学费，算不上生活费与住宿**

- 官方事实：各校住宿与生活成本**另计**（见第 HK-002 条、第 HK-015 条）；港硕学费**逐校逐课差到两倍以上**（见第 HK-046 条）。
- **提示**：先按**官方分项**把「学费 + 住宿 + 生活」拼一遍，再看够不够。

**③ 指望「轻松上名校」**

- 官方事实：官方明确规定「**满足最低要求不保证录取**」，也不存在「低门槛、无标准成绩直接录取」的渠道；**伪造学历**会被**开除学籍**，**使用虚假文书**有**刑事后果**（见第 HK-012 条）。
- 官方还明文：「**Admissions is selective and meeting these minimum requirements does not guarantee admissions.**」（见第 HK-006 条）
- **提示**：**没有任何一条官方通道**能让「成绩不够」变成「能录取」。

**④ 指望「读书顺便打工养活自己」**

- 官方事实（入境处 **ID(C)996 (05/2025)** 第 20 段）：以学生身份来港者「**不得：(i) 接受有薪或无薪的雇佣工作；或 (ii) 开办或参与任何业务。**」
- 仅三种豁免：**校园兼职（每周 ≤20 小时）**、**暑假（6/1–8/31）**、**经院校批准的实习**。
- 官方另明说：**违反逗留条件**留在香港，「**不会**被视为通常居住在香港」——**会连带影响七年的计算**（见第 HK-025、HK-029 条）。
- **提示**：把「留学」当「打工挣钱」的路径，在**制度上就走不通**。

**⑤ 孩子英语长期在及格线附近**

- 官方事实：港校硕士英语门槛是**明码**的——港大 **IELTS 6.0**（文学院部分课程 **7.0**）、中大 **6.5**、理大 **6.0**、城大 **6.0**（见第 HK-047 条）；本科国际课程通道同样有 **IELTS / TOEFL** 门槛（见第 HK-001 条）。
- **提示**：英语不是「去了自然会好」，而是**申请时的硬门槛**。

**⑥ 把「读完就能留下」当成必然**

- 官方事实：**IANG 首次**应届确实**不用先有工作**，但**只留 24 个月**；**续签时必须已获聘用**；**身份**要**连续通常居住满七年**，且**由入境处个案认定**（见第 HK-029 条）。
- **提示**：把「留下来的概率」当成**市场决定的变量**，而不是家庭的**既定计划**。

**⑦ 打算靠「降一级插班」提高录取机会**

- 官方事实：**年级由学校按校本机制评定**，官方明文**不应在同一学年期间安排学生升级或降级**；中学**整体重读生比率不得超逾 5%**（见第 HK-036 条）。
- **提示**：这套做法在香港**没有操作空间**。

**⑧ 不能接受「年级由学校定」**

- 官方事实：「**学校提供的学位未必能完全符合申请人的意愿，包括欲就读的级别和欲修读的选修科。**」（见第 HK-036 条）
- **提示**：若「必须读某一级」是不可让渡的条件，会被现实的学位安排反复冲撞。

**⑨ 把「中介说」当作决策依据**

- 官方事实：港大官方**严正声明**——**未授权任何中介**招生；普通法框架下，中介的服务合约受《商品说明条例》（第 362 章）等约束（见第 HK-010 条）。
- **提示**：**所有关键数字回官方原文**；这是本指南存在的理由。

**⑩ 家庭完全无法接受「孩子将来回内地就业 / 发展」**

- 说明：这一条**纯属经验提示**，**官方无任何相关文件**。
- **提示**：香港与内地是两个不同的就业市场；把「必须留港」当成前提，会让整个决策失去弹性。

**红线提醒**

- **别用「别人家孩子去了」当理由**——**每个家庭的预算、意愿、英语基础都不同**。
- **别把「读港校」当成「拿身份」的捷径**——四件事要逐环达标（见第 HK-029 条）。
- **别忽略孩子自己的意愿**——这是**最长的那条线**。
- **别在预算上打「差不多」的主意**——学费、住宿、生活**都是官方可查的分项**（见第 HK-002、HK-015、HK-046 条）。
- **别把这条当官方结论**——**本条是经验提示（C 级）**，官方**没有**此类判定标准。

**常见误传**

1. **「成绩不好也可以去香港读书，那边门槛低」**——**官方没有这条通道**。港校官方明文「**满足最低要求不保证录取**」；且**伪造学历**会被开除、**虚假文书**有刑责。
2. **「去了香港打工就能补贴学费」**——**制度上不允许**。学生签证原则上**不得受雇工作**，只有三种豁免。
3. **「读完书留下来是顺理成章的」**——**不成立**。IANG 续签**须已获聘用**；身份要**七年连续通常居住**且**个案认定**。
4. **「内地读书和去香港读书，将来出路差不多」**——**这是判断题，不是事实题**。官方**没有任何**两地对标文件；本条**不替读者下这个结论**。
5. **「官方有一套『适合留学的孩子画像』」**——**没有**。官方只有报考资格、入学要求与签证规则，**没有**人群画像类文档。

**适用人群 + 入学年度**

- **谁该看**：正在做「要不要送孩子去香港」这个决定的家庭；已经被中介推着往前走的家长。
- **入学年度**：不适用（本条属决策提示）。

**解决什么焦虑 + 风险等级 + 决策阶段**

- **风险等级**：中——判断错配的代价是**几十万到上百万的投入 + 孩子的几年时间**；但不会造成身份或法律风险。
- **解决什么焦虑**：取舍（要不要去）。
- **决策阶段**：要不要去。

**关键节点与时效**

- 本条无时间节点（属决策提示）。
- 涉及的具体节点见第 HK-001、HK-009、HK-032、HK-039、HK-045 条。
