## 三、本条的写法定性：把「概率」翻译成「可问的问题」

家长最容易误读的，是**把学校公布的升学率当成自己孩子的成功率**。本条不做预测，而是把三个概率各自对应的**追问方式**写出来（这是谁的升学率／升到哪里去／读完能否留港），并：
- 只引**一所院校**的官方数字作样本，**不横向拉表**（各校统计口径不同，横比会产生新的误导）；
- 把「副学位不能直接留港」这条最贵的误传**显式写进红线与误传**，并指向 HK-023 已核过的官方规则。

## 四、与相邻条目的关系

- 与 **HK-023（IANG 路径，文件 003）**：本条第三个概率直接依赖 HK-023 的官方结论（IANG 门槛＝学士或更高）；两条必须口径一致，任一改动须回扫另一条。
- 与 **HK-014（条件录取，文件 016）**：副学士升本科同样涉及「有条件录取／衔接条件」，两条在「条件未达成不等于结果」上是同一逻辑。
- 与 **HK-003（成绩能申哪一档，文件 005）**：本条是 HK-003 在「成绩不理想」情形下的**下游选项**，两条合看才完整。
