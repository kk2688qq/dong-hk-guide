## 三、刻意未写死的

1. **「政府强制非本地生买医疗险」**：**未找到**——正文显式注明这是**校方规定**，**不是政府规定**。
2. **「保单核对清单」的官方模板**：**未见**统一官方模板；核对要点系据各校官网**保障范围表述**整理，已注明出处。
3. **其余院校（浸大 / 岭大 / 教大 / 都会大学 / 演艺学院）的保险政策**：本轮**未逐校核到**，不写。

## 四、被排除的信源

- 保险中介 / 留学机构整理的「香港留学生保险对比」：**排除**——非官方，且常把「校方强制」说成「政府强制」。
- 「香港留学生看病全免费」类说法：**作为误传反驳对象**列出。

## 五、复核提示

1. **保费与学年强绑定**（判例 1）：复核时**逐校回官网确认当前学年**，尤其是港科大（现引 2025/26）与港城大（现引 2026-27）。
2. 「**强制 / 建议 / 自理**」三档**可能随学年变化**（港理大 2024/25 就是从「代购」改为「自理」），复核须重看政策档位。
3. 与 **HK-015（宿舍 vs 租房）**、**HK-017（抵港必办）**同属「落地」类，三条一起回扫。
