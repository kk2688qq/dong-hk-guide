## 四、刻意未写死的

1. **申请费金额**：以入境处当时公布为准，**不写死**（判例 5）。
2. **配额数字**：官方称**无配额**，正文**不编数字**。
3. **行业名单**：官方称**不限行业**；「人才清单」为便利措施，**不写成准入限制**。
4. **「赴港工作同意书」的具体签发单位**：官方写「现时工作单位／档案所在单位」，**不细化**。

## 五、被排除的信源

- 中介整理的「专才办理流程 / 包批」：**排除**——非官方，且常宣称「先办身份再找工作」。
- 小红书、知乎「专才攻略」：排除。
