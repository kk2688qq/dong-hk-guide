## 三、刻意未写死项

| 项 | 原因 |
| --- | --- |
| 申请费／签发费的**具体金额** | 官方收费页（`specifiedschemes.html`）随调整变动，写死会过期；正文只写「须缴、不可退还」并指向现行页 |

## 四、与相邻条目的关系

- 与 **HK-020（高才通 B/C 类）**、**HK-021（优才）**：那两条讲「怎么拿到保证人身份」，本条讲「拿到身份后家属怎么来」。三者构成身份线的一条链。
- 与 **HK-025（学生签证与身份衔接）**：就读路径的受养人限制（12 个月、不可工作）是这两条的交叉点，撰写 HK-025 时需回引本条。
