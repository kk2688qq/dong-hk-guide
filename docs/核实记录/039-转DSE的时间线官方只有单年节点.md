## 三、刻意未写死的

1. **「初一至初三黄金期」时间轴**：**官方无**；正文已标明属**推算（C 级）**。
2. **各年级插班的官方「衔接节点」**：**未找到**；官方只有「学校面见评估年级」。
3. **「（暂定）」字样**：DSE 表内除「报名」「缴费」外多数活动标「**（暂定）**」，正文**照抄「暂定」**，不省略。
4. **中一派位日期**：正文**显式注明这是中一派位、不是插班日程**，避免读者误用。

## 四、被排除的信源

- 商业媒体（`hk01` / `hket` / `stheadline`）转载的「JUPAS 日程」「DSE 放榜日」：**排除**——即使与官方一致，仍回官方原文核对（判例 2）。
- 中介「DSE 时间规划表」：**排除**——按年级编排的属自拟，官方无。

## 五、复核提示

1. **DSE 与 JUPAS 的节点逐年度重排**（本条目锚定 **2027 年文凭试 / 2027 年度联招**），复核须回考评局「重要日期」与联招处「申请时间及费用」页。
2. **放榜日历年约在 7 月中旬**，复核须确认当年官方公布（带「暂定」）。
3. 与 **HK-038（转 DSE 资格）**、**HK-032（倒推时间表）**、**HK-031（联招居港规定）**同源，四条一起回扫。
