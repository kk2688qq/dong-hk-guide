## 三、刻意未写死的（**最易误传点**）

1. **「认可院校名单（985 / 211 / 双非分档）」**：**五校官方全部无此明文**——正文**明说官方无此规定**；中介的「985/211 80–85＋、双非 87＋」**一律不引**。
2. **「双非本科不得申请」/「双非需 XX 均分」**：**官方无任何此类原文**。
3. **CET-6 是否被接受**：**各校不一**——城大**明列**、理大**旧版亦列**；**港大 / 中大 / 科大官方页未列**；正文**分校分写**。
4. **科大英语最低分**：本次**未逐字核到具体分数**，正文**不写具体数字**，依据栏只给官方入学要求页链接。
5. **「同一学历在不同校的认可范围差异的官方对照」**：**未找到**官方对照文件，只能逐校引用。

## 四、被排除的信源

- 留学机构（新航道、新东方、港智优、寰兴等）的「双非 / 985 / 211 均分门槛表」：**排除**——官方无此明文（判例 2）。
- 「双非保过 / 内部名单」类宣传：**排除**——港大官方严正声明**不存在**此类渠道。
- 知乎 / 小红书「双非申港硕经验帖」：排除。

## 五、复核提示

1. **英语分制切换**：多校自 **2026-01-21** 起改用新托福分制（港大 80→4.5；理大 80/120→4.5/6；城大 79→4；中大 79/120→4.5/6）——复核须确认**当时分制**。
2. **科大英语最低分**须补核后写入依据栏。
3. 与 **HK-006（最低要求 vs 实际录取）**、**HK-045（时间线）**、**HK-046（学费）**同属申硕段，四条一起回扫。
