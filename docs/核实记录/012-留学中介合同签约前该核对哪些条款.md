## 三、刻意未写死的 / 已更正的一处

1. **任务单原写「《服务提供者（提供服务）条例》（第 625 章）」——该条例不存在**。经 elegislation 直接核实：**第 625 章实为《电子健康纪录互通系统条例》**；与「服务提供者」相关的正确条例是**第 457 章《服务提供（隐含条款）条例》**。**本条已按第 457 章处理**（勘察记录中已记更正）。
2. **香港无「留学 / 升学中介」专门监管法例、发牌制度或官方合同范本**——正文**明说**；条目中的「必读条款清单」系**作者依第 362 / 457 / 71 章法定框架整理的应用性清单**，**非官方文件转述**。
3. **教育局「招生代理」官方说明 / 警示**：**未找到**。
4. **海关针对「留学中介」行业的专项执法警示**：**未找到**（执法案例集中在美容、健身、零售等行业）；但条文**明文涵盖服务**、适用于一切商户（有海关专页与 2017 年立法会答复佐证）。
5. **消委会报告**：**法定机构、非政府机关**，**不进依据栏**，正文只作背景并注明「非官方一手」。

## 四、被排除的信源

- 中介「合同范本 / 必读条款」：**排除**——非官方，且常回避上述法定框架。
- 「维权指南」类自媒体稿：排除——常引错误条例号（如把不存在的第 625 章当真）。
- 消委会以外的媒体转载：排除。
