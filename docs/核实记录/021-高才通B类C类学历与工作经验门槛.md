## 刻意未写死的数字

- **合资格大学综合名单**：由劳工及福利局按四个世界大学排名定期更新，本条不逐一列举院校，只给现行名单页链接。
- **C 类年度配额的具体数字**：官方指南只表述「受年度配额限制、先到先得」，未列数字，故不写。
- **申请费 / 签发费具体金额**：S3 收费页会调整，故只写费用结构并给出查证链接。
