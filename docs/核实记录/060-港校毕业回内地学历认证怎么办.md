## 三、刻意未写死的数字及原因

| 项 | 处理 | 原因 |
|---|---|---|
| **通过率** | **不写** | 官方**从未公布任何通过率**（S1–S7 全部未见）。铁律 4：不承诺结果。 |
| **最低在港天数（如「180 天」）** | **写成否定性结论** | 官方文本中**未见**任何天数门槛；只在答问中给「个案评估」。故写成「官方未设定最低在港天数」，而非填一个数。 |
| **香港副学士／高级文凭等非学士以上学历是否受理** | **不替官方下结论** | 受理范围写「学士以上（含学士）」；此类**官方未核到**逐条解释 → 明确标注「官方未核到」，不下判断。 |
| **是否存在《认证办法》2024／2025 修订版** | **标注「未核到」** | 现行仍为 2023-01-28 施行版；不臆测新版存在。 |
