## 三、刻意未写死 / 明确不写的（本次最关键的一节）

1. **「降级策略」一词本身**：EDB / HKEAA / elegislation **均无**此提法；正文改用官方语汇「**留级 / 重读**」，**不造词**。
2. **香港 / 内地「年级—年龄」对应表**：**未找到任何官方对应表**；正文只写「学校面见评估年级」（A 级），**不给对应关系**（属 C）。
3. **「超龄」是否影响派位 / 获资助**：**未找到专门条文**。公营学位派位（SSPA）**只覆盖参加派位小学的小六学生**，本身不处理初中段插班。→ **正文不写「超龄不能派位 / 不能资助」**（属无据推论）。
4. **「降级对 DSE / 升学的影响」**：**官方无直接表述**。正文只引「DSE 报考资格无年龄上限」（A 级事实，见 HK-038），**不下因果判断**。
5. **《教育规例》（第 279A 章）**：elegislation 为 JS 动态渲染、PDF 端点返回空壳，**未能完整覆核全文** ⇒ 只记「**本次未找到**」，**不断言该规例没有**。
6. **《学校行政手册》适用范围**：手册开篇明写「**本手册适用于资助学校**」——**不适用于直资 / 私立**；正文已在红线提醒中注明。
