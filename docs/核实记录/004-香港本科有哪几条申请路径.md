## 二、逐项对照

| 条目表述 | 官方原文（逐字） | 判定 |
| --- | --- | --- |
| 港中大走统招提前批，不需直接向校方申请 | 「本校通过『全国普通高校统一招生计划(高考)』招收内地高考生，**获国家教育部列入提前录取批次**。高考生**不需直接向本校申请**」 | ✅ 一致 |
| 港中大录取不设面试，以高考成绩择优 | 「录取时，**本校不设面试，以高考成绩（不含加分）择优录取**」（国标码 81002） | ✅ 一致 |
| 独立招生与内地统招互不影响 | 港大「**申请香港大学与参加内地统招互不影响**，且申请者可同时参加内地高校招生计划（如强基计划等）」 | ✅ 一致 |
| 接受录取后不再参加内地高招录取 | 港大「**接受香港大学录取后，申请者将不再参加内地高招录取程序**」；港科大「**获得中国香港自主招生院校录取的学生，中国内地统招高校将不再予以录取**」 | ✅ 一致 |
| 港城大自 2026 学年起改为单独招生 | 「**自2026学年起**，香港城市大学……透过『**中国内地高考单独招生**』独立招收中国内地应届高考生，**不参加『全国普通高等学校统一招生计划（统招）』，不占统招志愿**」 | ✅ 一致 |
| 应届高考生不符合国际学历通道 | 港中大「Students from the Chinese Mainland who are **current Gaokao candidates (应届高考生) are not eligible** to apply through this Scheme」 | ✅ 一致 |
| 国际学历要求（IB / A-Level / SAT+AP） | 港中大「**GCE AL / International AL: 3AL passes / 2AL+2AS passes**」；港大「a **minimum of 3 A-level subjects**」「a minimum of **3 AP subjects**; AND **SAT**, or 2 additional AP subjects」 | ✅ 一致 |
| 语言门槛最低示例 IELTS 6.0 / TOEFL 80 | 港中大「**IELTS (Academic) 6.0 (Overall Band Score)**」「TOEFL (iBT) 80」 | ✅ 一致 |
| 副学士要求：高考达本科线 + 英语达满分 60% + 须面试 | HKU SPACE「**高考成绩达所属省 / 市的本科线\*或以上**，以及**英国语文科达所属省 / 市满分之60%**」「**申请人须通过面试**」「**满足入学要求并不能保证录取**」 | ✅ 一致 |
| 内地应届高考生走不了 JUPAS | 联招处「**已获取香港中学文凭考试（DSE）成绩及／或应考该入学年度的香港中学文凭考试**」；「**未符合『大学联招办法』申请资格规定的人士，不得透过『大学联招办法』递交申请**」 | ✅ 一致 |
| 不得同年度联招 + 非联招双申 | 联招处「**申请人不得在同一学年内，就任何可经『大学联招办法』选报的课程，同时透过『大学联招办法』及非『大学联招办法』途径申请**」 | ✅ 一致 |

## 三、刻意未写死 / 明确不写的

1. **港科大 / 港城大 / 港理大的国际课程分档要求**：本轮**未逐页核到官方原文**，正文「待核实」栏已明说，**不写推断**。
2. **各附属学院副学士的「官方升学率」**：官方只公布**个别升学案例**，**无统一官方数字**，不写。
3. **港中大各省提前批填报日期**：官方要求「向所属省、市、自治区考试院查询」，**各校不公布统一日期**，不写死。
4. **非大学附属副学士的升学率**：同上，机构宣传数字**不属 A 级**，排除。

## 四、被排除的信源

- 商业留学站点（港智优、新东方前途、富洋国际等）整理的「香港本科申请路径图」：**排除**——非官方，数字与官方一致也不作依据。
- 知乎、公众号、小红书「港校申请攻略」：排除。
- 中介「港城大仍走统招」「内地生可走 JUPAS」类说法：**作为误传反驳对象**列出，不引为依据。

## 五、复核提示

1. **各校报名开放 / 截止日逐年更新**，复核时**逐校回官网**核对（本条目锚定 2026 / 2027 年度）。
2. **港城大 2026 学年改独立招生**是新变动，若官方再调整须立即改本条与 HK-009。
3. 与 **HK-009（申请时间线）**、**HK-014（条件录取 vs 无条件录取）**、**HK-006（最低要求 vs 实际录取）**同源，四条一起回扫。
