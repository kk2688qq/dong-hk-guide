## 三、⚠️ 本条为什么是 C 级（以及「C 级怎么写」）

交接书 J 段第 1 条已说明：**HK-058 的采集数据缺失**（关键词「香港粤语」连续两次服务端超时），该条「可先按『无官方数字、经验性描述、证据等级 C』写」。

本条的处理是**双向的**，这是它作为 C 级条目的范式：

| 方向 | 做法 |
|---|---|
| **官方确实存在的** | **标明出处**（S1–S6）——政府计划（虽排除学生）＋三校校内服务 |
| **官方没有的** | **明说是经验 + 标注 C**——孤独感、朋友圈、身份认同、「多久学会粤语」 |
| **禁止动作** | **不编数据**（无「X% 内地生感到孤独」「Y 个月学会粤语」这类数字） |

**核心价值**：本条纠正了一个**常见误解**（「凭学生签证也能申请政府粤语津贴」），同时又**没有因为无数据而放弃可用信息**（校内资源逐校可查）。

## 四、刻意未写死的数字及原因

| 项 | 处理 | 原因 |
|---|---|---|
| **「X% 内地生感到孤独」类数据** | **一条都不写** | **无官方统一口径**；红线：**禁编数据**。 |
| **「多久能学会粤语」／「Y 个月速成」** | **写成否定性结论** | **无官方口径**；「三个月学会粤语」类说法**一律不采信**。常见误传第 3 条。 |
| **专门面向「内地来港留学生」的政府统一计划** | **未核到 → 不写** | 现有计划面向「**新来港定居人士**」及少数族裔，且**明确排除就读签证人士**。常见误传第 2 条。 |
| **粤语能力是否为入读／居留条件** | **不替官方下结论** | **未核到**官方设此条件的表述。常见误传第 5 条。 |
| **其他地区的融入经验** | **不引** | 红线：只用中国香港内容。 |
