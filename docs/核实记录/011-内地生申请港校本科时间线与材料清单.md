## 三、刻意未写死 / 明确不写的

1. **「家长 / 学生分工」**：官方**无原文**，正文已标 **C 级（作者经验，非官方口径）**，不进「依据栏」当官方来源。
2. **本科高考直申的「推荐信 / 个人陈述 / 学信网验证报告」**：官方**无此要求**，已在「常见误传」中显式反驳，**不补进正文当材料**。
3. **申请费金额**：只写官方页当时数字，并注明「以各校官方页当时数字为准」（费用会调整，判例 5）。
4. **港中大各省填报日期**：官方要求向省考试院查询，**不公布统一日期**。

## 四、被排除的信源

- 商业机构整理的「港校申请时间表 / 材料清单大全」：**排除**——非官方汇总，常把研究生材料套到本科。
- 「港校申请要准备推荐信 PS」类自媒体稿：**排除**——查无官方原文（已列为误传第 1 条）。
- 知乎、公众号、小红书攻略帖：排除。

## 五、复核提示

1. **各校开放 / 截止日逐年更新**，复核时**逐校回官网**（本条目锚定 2026/27 与 2027 年度）。
2. 与 **HK-001（申请路径）**、**HK-014（条件录取 vs 无条件）**、**HK-013（留位费）**同源，四条一起回扫。
3. 若某校从独立招生改回统招（或反之），本条与 HK-001 须同时改。
