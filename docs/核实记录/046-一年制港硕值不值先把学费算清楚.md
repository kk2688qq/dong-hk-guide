## 三、刻意未写死的（**最易误传点**）

1. **「授课式硕士统一学费数字」**：**不存在**——正文按校按课带学年逐条列。
2. **「本地 / 非本地学费差异」统一规则**：**无统一规则**（理大仅「部分课程」有别），正文已写。
3. **「内地生读港硕一年总花费」**：**未找到官方总账**；正文**不编总账**，如引用须按官方分项拼装并标 B 级。
4. **港大《General Information NJ 2026》PDF 的 HK$47,000 / HK$224,000 / HK$249,000**：**是本科非联招学费**，**不得当作 TPG 学费**——正文已在红线提醒中明确。
5. **「一年制」**：正文已明写**非统计一学制**（1 / 1.5 / 2 年并存，均有官方例）。

## 四、被排除的信源

- 中介「港硕学费 10–30 万 / 年」类区间表述：**排除**——**无学年、无课程**，判例 1 / 2 直接判不可用。
- 中介「港硕一年总花费 XX 万」：**排除**——官方无总账。
- 知乎 / 小红书「港硕学费汇总」：排除。

## 五、复核提示

1. **学费逐年调整、且逐课不同**——复核须**逐课回官方课程页**，并按**当年学年**整体更新（判例 1）。
2. **港大 / 城大按学分计价**的课程，总学费随**选课学分**变化，复核须同时核**学分要求**。
3. 与 **HK-045（时间线）**、**HK-047（双非）**、**HK-002（本科一年总花费）**同属费用类，四条一起回扫。
