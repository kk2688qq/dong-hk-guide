## 四、刻意未写死的数字及原因

| 项 | 处理 | 原因 |
|---|---|---|
| **官方是否正式使用「八大」** | **未核到 → 不写** | 官方对应表述为「八所教资会资助大学」。常见误传第 5 条相关。 |
| **VTC「13 所成员机构」逐所名称** | **不列全** | 本次仅从香港年报 2023 摘得**示例**，**完整名录未逐一核到**（VTC 官网不在本次信源范围，**未采用**）。 |
| **「野鸡」类判断** | **不写**（并明确否定） | 官方分类体系里**没有**这个概念；官方政策是**两个界别并行发展**。红线提醒第三条。 |
| **任何排名数据** | **一律不摘录、不采用** | 教育局某官方页与某校宣传卡**含 QS 排名段落**，本项目按红线**不摘录**。常见误传第 5 条。 |
| **各校档次／优劣** | **不做** | 红线：不排名、不做校际比较。 |

## 五、被排除的黑名单信源

| 信源 | 说了什么 | 排除理由 |
|---|---|---|
| 「香港只有八大，其余都是野鸡」 | 贬抑性判断 | **与官方名录不符**（22 所学位颁授院校）；官方分类说的是**拨款来源与法例依据，不是档次**。常见误传第 1 条。 |
| 「教大／岭南不算八所大学之一」 | 事实错误 | **官方名录里在**（S4）。常见误传第 2 条。 |
| 「都会／树仁／恒生是学院不是大学」 | 名称过时 | **官方名称就是「大学」**；树仁 2006 正名、恒大 2018 获批（S9／S10）。常见误传第 3 条。 |
| 「官网上有排名，所以官方按排名分档」 | 推断 | **推断不成立**；排名是第三方榜单。常见误传第 5 条。 |
| 自媒体「港校梯队图」 | 分档 | **官方无此分级**（详见 HK-059）。常见误传第 4 条。 |
