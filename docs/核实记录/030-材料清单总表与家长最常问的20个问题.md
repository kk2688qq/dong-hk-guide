## 一、本条的性质（**先说清，这是拼装件**）

- **官方从来没有一份「赴港留学材料总表」。** 本条是把**各条目已经逐字核过的官方要求**，**按阶段拼装**成一张可打印的表；再加 20 个高频问题，每个答案指到有官方依据的条目。
- **处置方式**：表内每一项都标了「见 HK-0XX」；**本条不产生新的数字或结论**。
- **证据等级标 B**（不是 A）：原因是本条**含经验整理成分**——「**家长 / 学生分工**」**官方无原文**（HK-009 已注明），且「**哪些材料不必准备**」属**经验层面的提示**（虽以官方「不需要」为据，但官方不会专门发文件说「不需要什么」）。

## 四、刻意未写死的（**B 级的原因**）

1. **「家长 / 学生分工」**：**官方无原文**——本条**不给分工安排**，只在正文注明属经验层面（与 HK-009 一致）。
2. **金额一律不写死**：申请费、签证费、留位费**随官方调整**——本条只给「按校收 / 不可退」这类**性质**，不给金额（金额见对应条目，且须回官方页当时数字）。
3. **逐校材料差异不展开**：本条只列**共通必办项**；面试形式、补充表格等**逐校差异**须回各校官方页。
4. **「抵港必办清单」不编造**：银行开户、电话卡**无官方办理规定**——本条**明说「没有官方依据」**，不拼一个假清单（同 HK-017 的处置原则）。
5. **身份证 30 天 / 180 天前提**：**照法例原文写**（第 177 章 / 第 177A 章），不改写成「7 天」这类坊间说法。

## 五、被排除的信源

- 中介「赴港材料清单」表格：**排除**——把不需要的材料（推荐信、个人陈述、学信网报告）也列进去，属**加料收费**。
- 「抵港 7 天必办清单」类网文：**排除**——官方无此文件（HK-017 已核）。
- 「XX 大全 / 最全清单」类帖子：**排除**——无官方出处，且常与官方要求相反。

## 六、复核提示

1. **本条的复核方式是「逐项回源」**：表内每一行点进「见」栏所指条目，确认该条目的官方要求**未变**。
2. **两类最易过期**：① **各校申请费与截止日**（每年调整）；② **学生签证的逗留与豁免条款**（指南改版则段号位移）。
3. **回扫触发条件**：HK-008 / HK-009 / HK-017 / HK-013 / HK-014 / HK-016 任一条目改动，**本表须同步**。
4. **与 HK-028 的分工**：**HK-028 管「哪些说法是错的」，本条管「该带什么、去问谁」**——两条互为索引，不得互相替代。
