## 二、可成文结论（正文即据此写）

1. **【A】「国际学校」是官方名册概念**，有确切数量与非本地课程体系清单。
2. **【A】没有统一招生／统一派位** → 「档次相当」**问错了方向**；能核的是「年龄＋学段＋课程体系＋申请窗口」。
3. **【A】「收生年级」的官方抓手＝年龄区间 ＋ 学段**（官方检索页逐校给出）。
4. **【A·风险披露】官方自己提示非学术录取因素与债券／提名权**——「交钱就能进」的风险提示是**官方原文**，不是我们推断。

## 三、写法纪律（克制说明）

1. **不给「档次」判断。** 官方**无任何学校排名／档次口径** → 本条**不提供档次对照**；正文在「常见误传」与「待核实」两处**显式写明**「凡需档次参照者属作者经验（C 级），本条不作」。
2. **名册示例 ≠ 推荐。** 正文举的三所学校的年龄／学段，是**官方公开事实**，并**显式标注「不是推荐」**。
3. **不引任何被排除信源。** 勘察第四节列出的 5 个商用机构／汇总站（启德、LINKEDU、studyu、universityadmissionbd、collegedunia 等）**一律未引**，即便其数字与官方一致也只作旁证、不作依据（项目红线）。
4. **不做「内地校 → 香港校」映射。** 两地问**无官方换算关系**，本条**不建映射表**。
5. **交叉引用只引已落地条目。** 引 **HK-036**（插班年级承认各校自订）——已落地，引用成立。
