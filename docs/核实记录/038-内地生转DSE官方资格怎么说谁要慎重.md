## 三、刻意未写死的

1. **「DSE 与内地高考的差异」**：官方**无对比文档**；正文**不作官方结论**，只引官方「DSE 于本港与全球均获广泛认可」的表述。
2. **「谁适合 / 谁不适合转 DSE」**：官方**无画像文档**；正文已显式标为**作者分析（C 级）**。
3. **内地「与考学校」扩容名单**：新闻稿措辞为「**探讨**」「**可按程序申请**」，**未定案**；正文**照抄措辞，不写成既成事实**。
4. **丙类其他语言**含「印地语（由 2028 文凭试起）」——**已注明生效年度**，不写成现行。

## 四、被排除的信源

- 中介 / 自媒体「转 DSE 上名校」「DSE 比高考容易」类稿件：**排除**——官方无对比依据（已列为误传第 3 条）。
- 「DSE 与考学校名单」商业机构整理版：**排除**——只引考评局官方名单页与新闻稿。
- 内地补课机构「保送 DSE」宣传：**排除**——官方在明打「借壳办学」。

## 五、复核提示

1. **「与考学校」名单与扩容进度须逐次回考评局新闻稿核对**（现为「四所 + 拟增八所」）。
2. **丙类语言科目**随年份增加（印地语自 2028 起），复核须看当时科目表。
3. 与 **HK-039（转 DSE 时间线）**、**HK-033（Band）**同属中学段，三条一起回扫。
