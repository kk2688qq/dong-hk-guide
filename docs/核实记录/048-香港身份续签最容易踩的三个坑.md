## 四、刻意未写死的数字及原因

| 项 | 处理 | 原因 |
|---|---|---|
| **「在港住满 183 天／半年」门槛** | **写成否定性结论** | 两份指南**均无**天数硬门槛；高才通/专才把「留港的时间」列为**考虑因素之一**，优才则明确要求「已在香港居住」。故写成规则原文，**不推结果**。 |
| **「二次续签收紧」** | **不写** | **未核到**任何「第二次及以后另行收紧」的官方条文或公报。 |
| **高才通 C 类年度配额数字** | **不写** | 官方只表述「受年度配额限制，先到先得」，**无固定数字**。 |
| **优才／专才网页版本号** | **标注「网页无版本号」** | 网页无版本印记，仅 PDF 指南有 04/2026；不臆造网页版本。 |
| **各计划具体申请费金额** | **不写具体数额** | 收费架构在「指明计划」页（S7），本条只写「不可退还的申请费及签证签发费**（收费架构见该页）**」，避免数字脱期。 |
