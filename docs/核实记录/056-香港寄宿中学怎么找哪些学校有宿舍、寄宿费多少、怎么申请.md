## 三、🔴 「数字对但来源／年份不对」专项（本条的核心理由）

> 这是本条**最值得保留的证据链**——四个流传数字，**每个都「有出处、但出处或年份不对」**：

| 流传数字 | 实际官方数字 | 问题性质 |
|---|---|---|
| 圣士提反书院全年寄宿费 **HK$82,900** | 最新《收费证明书》（2026/27）**86,300／年** | **旧数字**（年份不对）→ 常见误传第 5 条 |
| 保良局颜宝铃书院「**8,000/月**、5 日制 8,000／7 日制 9,470」 | 最新《收费证明书》（2026/27）**8,420／月（全年 84,200）+ 周末 1,550／月（15,500）** | **旧年数字** → 常见误传第 6 条 |
| 香港复临学校「5 天 **57,200**／7 天 **74,700**」 | 官网 **2026-2027 学年**：**58,350／76,200** | **上一学年数字** → 常见误传第 7 条 |
| 培侨中学「寄宿费 **38,200 元/年**」 | 官方清单为**区间**「**29 820 – 42 600**」（视乎 5 天／全周等） | **媒体取单一数值与官方口径不符** → 常见误传第 8 条 |

**核证方法**：教育局对学校收费采**逐校签发《收费证明书》**制度；直资校另在「直资计划学校资料」PDF 列「Boarding fee 宿费」栏。**必须核当学年版本**。

## 四、刻意未写死的数字及原因

| 项 | 处理 | 原因 |
|---|---|---|
| **「14 所」（及 16／18／20／21 所）寄宿中学** | **一律不用**（并明确否定） | **无官方来源**；官方**未提供统一名单**，数目随「是否计入小学、国际校、单一性别校」而变。常见误传第 1 条。 |
| **「寄宿费有全港统一标准」** | **写成否定性结论** | 教育局采**逐校《收费证明书》**制度，金额各不同。常见误传第 2 条。 |
| **「直资 1,710／私立 902」等宿位总数** | **不写** | **未核到**官方来源。常见误传第 3 条。 |
| **「宿位申请量超供给 3 倍」** | **不写** | **未有官方依据**。常见误传第 4 条。 |
| **赛马会体艺中学官方宿费** | **写「未核到」** | 《中学概览 2025/2026》该栏为「-」，**不填估算值**。 |
| **香港复临学校宿位官方总数** | **不写** | **未核到**逐字数字（仅见自媒体）。 |
| **全港寄宿中学「宿位总数」** | **不写** | 官方**未公布**统一数字。 |
| **「12 周岁以下不可住校」** | **不写** | 本次**未核到**官方条文（红线提醒第六条）。 |
| **培英中学／明爱圣若瑟中学／佛教筏可纪念中学是否设宿舍** | **列为待核实** | **未核到**各校官网寄宿页；教育局 2025/26 直资清单中「佛教筏可纪念中学」未见「Boarding fee」栏。 |

## 五、被排除的黑名单信源

| 信源 | 说了什么 | 排除理由 |
|---|---|---|
| **自媒体「香港寄宿中学全名单」** | 「14 所／16 所／18 所／21 所」 | **无官方来源**；官方未提供统一名单。 |
| **自媒体「宿位总数」** | 「直资 1,710／私立 902」 | **未核到官方来源**。 |
| **媒体转述旧学年宿费** | 82,900／8,000／57,200／38,200 | **数字对但年份或口径不对**（见第三节专项）；本条**一律回到当年《收费证明书》或校方官网**。 |
| 留学中介「寄宿申请包过」 | 承诺结果 | 官方口径是「学校会按其校本情况考虑申请」；**住宿与录取是两回事**（红线提醒）。 |
| 平台帖「住校就能保证学位」 | 误解 | 同上，已写入红线提醒。 |

## 六、链接巡检与环境限制说明

- 教育局**收费证明书**为逐校 PDF（路径 `schoolfee/<校号>.pdf`），**可直接下载**；直资清单与《中学概览》各校页均**可打开**。
- 本条**逐校核到 15 所**，但**明示「不代表全港穷尽名单」**——这是「官方无名单」的正确表述方式。
- **学年口径不可跨年套用**：本条各校数字分别标注 2025/26、2025-26、2025/2026、2026/27、2026-2027，条目已明示「不可跨年套用」。
- 本次无 404／410；**无死链**。
