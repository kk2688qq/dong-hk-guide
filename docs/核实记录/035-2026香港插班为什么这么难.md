## 三、**本轮修的一处口径**（2026-10-06，WB2 自查所改）

- **问题**：本条初稿在「说人话 / 要核对的硬项 / 常见误传 / 关键节点」四处用了「**2027/28 学年**」表述；而 **HK-031、HK-032** 两条（WB4 已抽审通过）刻意采用「**2027 年度联招**」口径，且 **HK-032 明文提醒「别把『2027 年度』和『2027/28 学年』混着算」**。同一事实两处口径不一，**违反「同一事实只许一处实现」的纪律**。
- **结论（已核清）**：两种表述**指同一年**——政府公报的「2027 至 28 学年」= 入读大学的学年 = 联招口径的「**2027 年度**」（英文公报亦写「the application cycle for the 2027/28 academic year commencing in October 2026」，与联招「2027 年度」报名期一致）。**风险不在年份，在误读**：家长易把「2027/28 学年」当成「孩子**中学**那一年的学年」，而实际的计算窗口是**前一个学年**（2026-06-01 至 2027-05-31），从而**算错整一年**。
- **处置**：本条**统一改为联招年度口径**（2027 年度 / 2028 年度起），**学年表述仅保留在政府公报的逐字引文里**，并在引文后加一行注明「公报用『学年』表述，指的就是 2027 年度联招与 2028 年度联招，两者指同一年」；详细换算指向 **HK-032**。
- **未动 HK-031 / HK-032**（WB4 已抽审通过）——其「年度口径」结论**与本次核查一致**，无需改内容；**仅 HK-032 误传 2 的措辞「年度口径错」可能被读成「2027/28 学年是错的」**（政府公报本身用学年），**已在致 WB4 信中列为待裁定条目**，不自判改动。
