## 三、克制说明（写这条时的四条取舍）

1. **只引官方分数线，不引任何录取率**。网传的「985 录取率 8.2%／8.6%」「本科录取率 51.7%／52.86%」**全部未写入正文当事实**——官方从不公布任何录取率。按 WB4-020 §2「B2 反向红线」，平台/媒体数据只用于内部排序，**不得进 `book/` 正文**。
2. **不引报考总人数**。官方公示的是「通过资格审核的考生**名单**」（附件），**公告正文未给总人数**；网传「12,449 人」等属非官方统计。正文因此改用**官方录取人数**（4688→5790→6238）陈述规模趋势，**且不据此反推录取率**。
3. **打假只打不成立的那一半**。「有香港身份就能报名联考」是**真的**（且不看居留年限），正文**如实写了这半句**并明确标注「这半句是真的」。只打「400 分上 985」这个分数神话——**打歪会失去可信度，也违背「只讲真话」的立条目的**。
4. **不替官方断言「985 = 高分线院校」**。官方原话只有「**部分院校**执行高分线，院校名单详见全国联招管理系统」。正文因此**不列名单**、不断言哪些学校执行高分线，只写官方原话 + 「名单在系统内、官方不公开汇总」。

## 四、脚本改动说明（按「先怀疑脚本」纪律）

`tools/check.py` 的标题校验原实现为 `re.search(r"\b\d{3}\b", rest)`——**会误伤标题里任何三位数字**。本条的标题按「标题按用户搜索词写」铁律必须含搜索词「**400 分上 985**」，而 **400 / 985 都是三位数字**，会被误报为「标题里出现了文件号」。

- **判定**：方案 A 的原意是「**文件号**不进标题」，不是「三位数字不进标题」。原实现过宽，属脚本侧假阳性。
- **处置**：收窄为只判「**本条自己的文件号**」是否出现在标题中（`(?<!\d){own}(?!\d)`，own = 文件名前三位）。
- **影响面**：不放松任何真实约束（文件号仍不得进标题）；仅消除对合法搜索词的误伤。
- **回归检验（已跑，5 例全过）**：①「400 分上 985」→ 不拦；②「043 开头的标题」→ **拦**；③「标题里含 043」→ **拦**；④其他三位数（750）→ 不拦；⑤无数字标题 → 不拦。
- **纪律**：**绝不为了过校验去改写标题**（如把「400 分上 985」写成「四百分上九八五」）——那是让工具改写内容。已记为 **CLAUDE.md 判例 22**。
