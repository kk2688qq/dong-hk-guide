## 三、刻意未写死的

1. **网传「港八大统一首轮 11/15、主轮 1/15」**：**官方无此统一轮次**，正文**作误传反驳**。
2. **内地生与本地生截止是否不同**：**无统一规定**——部分课程分设两个截止日（如城大某 EMBA：本地 2027-08-20 / 非本地 2027-07-14），**多数同一截止日**；正文写「须逐课核」，**不给统一结论**。
3. **城大逐课截止日**：只取**节选**并注明「逐课不同，以课程页为准」，**不写成全量清单**。

## 四、被排除的信源

- 中介 / 自媒体「港八大 27fall 申请时间表」「首轮 / 主轮汇总」：**排除**——官方无统一轮次。
- 「港硕申请攻略」类稿件：排除。

## 五、复核提示

1. **各课程开放 / 截止日逐年更新**，复核须**逐课回官方课程页**（本条目锚定 2026/27 与 2027/28）。
2. **理大申请费已由 2026/27 的 HK$500 更新为 2027/28 的 HK$600**——复核须重看费用页。
3. 与 **HK-046（学费）**、**HK-014（条件录取与付款）**同源，三条一起回扫。
