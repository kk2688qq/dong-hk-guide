## 三、刻意未写死 / 明确不写的

1. **「超龄不得插班」「学籍必须与年级匹配」「不许跳级」**：教育局官方文件中**未找到原文**，只作**误传**列出并注明「查无官方原文」——不写进正文事实。
2. **各校面试题难度、录取偏好**：官方无数据，不给结论。
3. **全港插班日程表**：官方无汇总，条目**只列本条目所引四校**并加「不代表全港」的显式限定。
4. **报名费金额**：只写本条所引学校官网明确写出的 **HK$75**，不写「全港统一 75 元」。

## 四、被排除的信源

- 中介/留学机构整理的「香港插班懒人包」「全港插班日程」：**排除**——非官方汇总，且常夹带「保证录取」类话术。
- 「2026 教育局新规：插班生年龄学籍必须匹配」类自媒体稿：**排除**——查无官方原文（已列为误传第 2 条）。
- 百度百科、知乎专栏：排除。

## 五、取数与巡检说明

- 各校页面为官网直接公布，属「校方一手」；在「某校考什么」这类**校方自订事项**上，校方官网是唯一权威来源。
- 链接巡检另跑 `--network`；`.edu.hk` 校网域名不在 `check.py` 白名单内，故本条**证据等级标 A 的同时**在依据栏同时给出 EDB 官方页（官方页为白名单来源），避免「标 A 但存在非白名单域名」告警。

## 六、复核提示

1. 各校日期**逐年更新**，复核时**逐校回官网**核对（本条目锚定 2026-2027 年度）。
2. EDB《学位安排支援服务常见问题》里「持学生签证不能读公营学校」是**前置门槛**，若官方修订须立即改本条与 HK-025。
3. 与 HK-033（Band）、HK-040（找学校）同源，三条一起回扫。
