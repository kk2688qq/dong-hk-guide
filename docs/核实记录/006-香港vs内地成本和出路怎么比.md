## 三、刻意未写死的（**本条最关键**）

1. **内地侧任何数字一律不引用。** 内地院校学费由各省、各校自定，**不在本项目信源范围内**；正文已用醒目提示写明「请查内地教育主管部门与目标院校官方发布」。**这是不做「成本对比表」的原因——不是没有数据，是数据不在本指南的信源边界内。**
2. **「香港 vs 内地哪边出路更好」不下结论。** 官方**没有任何两地对标文件**；正文明写这是「家庭自己的判断题」。
3. **本地生 / 非本地生的认定规则（本科层面）未展开。** 本条只引**具体学费数字**；认定规则须另核各校官方页。
4. **内地的「排他性」条款未引用内地文件。** 本条只引用**港校官方**转述的国家教育部规定（港科大简章），未直接引用内地主管部门文件。

## 四、被排除的信源

- 各类「香港 vs 内地花费对比表」自媒体文章：**排除**——含内地非官方数字。

- 商业站对「学费差距」的估算：**排除**——本条的香港侧数字全部回官方页，内地侧不写。
