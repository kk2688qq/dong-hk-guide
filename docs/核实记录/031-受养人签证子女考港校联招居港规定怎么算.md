## 三、刻意未写死项

- **不写出入境纪录证明的收费金额**：官方只写「付费申领」，无金额，回 GovHK 收费页核对。
- **不写 2026 年度考生的完整要求**：S1 以 2027 年度起的新规为主，2026 年度的适用以联招处当年公布为准，列入待核实。
- **不对个案下结论**：资格认定权在「大学联招处」与教育局，本条只复述官方条款（铁律 7）。

## 四、被排除的污染信源（判例 2 / 判例 5）

检索「受养人 联招 居港 新规」时首页 5 条**全为商业留学机构**（港智优 hkstedu.com、新东方前途、富洋国际、智瞳、新华报业转载稿）。其共性错误有两处，**均不作依据**、只在「常见误传」按官方原文反驳：

1. 把「**联招申请资格的居港规定**」说成「**本地生定义新规**」（落点错）；
2. 把官方**联招年度**口径（2027 年度 / 2028 年度起）写成「2027/28 学年 / 2028/29 学年」——**但要注意：「2027/28 学年」这个说法本身与政府公报一致（公报就用「学年」），错的不是名词，是把「入读学年」当成「计算窗口」**（窗口在前一年）。

## 六、2026-10-07 修正（执行 WB4-018 裁定）

- **问题**：正文「常见误传」第 2 条原把「2027/28 学年起满一年，2028/29 学年起满两年」判为「**年度口径错**」。**此判定站不住**——政府新闻公报（2025-07-31）**本身就用「2027 至 28 学年」表述**，英文版更写作 "the application cycle for the **2027/28 academic year** commencing in October 2026"。
- **真正的问题不是「错」、是「易误读」**：家长看到「2027/28 学年」，容易理解成「**孩子入读大学那一学年**要住满」；而实际的**计算窗口在前一年**（2026-06-01 至 2027-05-31）。差一年，整条时间表都错。
- **裁定与执行**：WB4-018 采纳「**保留联招年度口径、只改措辞**」的建议 → 正文第 2 条改为「**别把『入读学年』与『计算窗口』混着算**」，并写明「政府公报本身用学年、两者指同一年，差异在计算窗口在前一年」。
- **⚠️ 归属订正（如实记录）**：该「年度口径错」措辞**实际在 HK-031**，而我 10-06 的 029 信把它误写成「HK-032 误传 2」，**WB4-018 的裁定沿用了该错误编号**。本次按**实质**改到正确位置（本条），并已在致 WB4 的信中**如实披露该归属错误**。
