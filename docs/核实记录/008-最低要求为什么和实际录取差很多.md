## 三、刻意未写死的

1. **「最低要求」与「典型录取」的官方分档数字表**：**港校研究生层面未找到**；正文**不写「官方典型录取＝均分 XX」**（此类数字均为中介 / 案例推断）。
2. **「实际录取均分」的官方统计**：**未找到**。
3. **对内地本科的具体分数线**：官方**只给定性要求**，**不给百分制**。
4. **港大「expected lower boundary」原文**：**现行页未逐字核到**（现版只给「Satisfying the minimum requirements does not guarantee admissions.」）——正文**以现版为准**，不引旧句。

## 四、被排除的信源

- 中介「港校录取均分参考表」「保证录取」类标准：**排除**——官方不公布，且港大严正声明**未授权任何中介**招生。
- 「双非 87 分才有戏」类帖子：排除（见 HK-047）。
- 知乎 / 小红书「录取案例统计」：排除——个例不等于官方统计。
