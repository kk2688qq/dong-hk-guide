## 四、刻意未写死的

1. **「学生签 → 高才通 / 工作签」的转换条款**：**未找到**统一明文，正文写「另行申请、个案酌情」，**不编条文号**。
2. **「每天过关」如何计入不在港天数**：官方未定义（与 HK-037 同源），不写死。
3. **「不反对通知书」的审核标准**：官方称「个别获发」，**不写统一标准**。

## 五、被排除的信源

- 中介整理的「毕业后留港攻略」「IANG 办理流程」：**排除**——非官方，且常把「应届 / 非应届」门槛写反。
- 「学生签可以转工作签」类说法：**作为误传反驳对象**列出。

## 六、复核提示

1. **ID(C)991 与 ID(C)996 换版时段落号整体重排**，复核须同时重核 **HK-022 / HK-025 / HK-017** 三条的段号（判例 9）。
2. 与 **HK-003（IANG 路径）**、**HK-026（通常居住七年）**、**HK-024（受养人）**同源，四条一起回扫。
