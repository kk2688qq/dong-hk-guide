> 而不是一份没人碰过的静态文本。

**规则（2026-10-06 WB4 017 裁定）**

1. **只追加，不改不删**——已记录的行不做修改；更正以新增行的方式出现。
2. **不写任何联系方式**——本台账不出现微信/邮箱；联系方式只在 `meta/about.md` 与 `README.md`。
3. **随 Release 发布**，并合进单文件 HTML——让 AI 也能读到「这段内容被质疑过并核查过」。
4. **来源分三类**：读者（issue / 私信）、AI（放行前的机器挑错，见 CLAUDE.md）、内部（WB2/WB4 自查）。
5. **每条必须有官方原文段落号或直达链接**——没有依据的判定不入账。
